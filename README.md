WuwaTappo Android
『명조: 워더링 웨이브』 공식 데스크탑 펫 [Wuwa Tappo]의 비공식 안드로이드 포팅 앱
현재 대응 원본 버전: Desktop 1.0.5 · 최신 빌드: 1.0.5 v3.2.2

데스크탑 버전의 계정·외형·보물상자·멀티플레이 기능을 그대로 유지하면서, 안드로이드 환경에 맞춘 플로팅 펫, 백그라운드 입력 집계, 홈 화면 배경 커스터마이징, 인앱 자동 업데이트 기능을 제공합니다.

다운로드 및 설치
Releases에서 최신 WuwaTappo-android.apk를 다운로드해 설치합니다.
최소 지원 버전: Android 8.0 (API 26) 이상
동일 서명 키로 배포되므로 기존 버전 위에 바로 덮어쓰기 업데이트가 가능합니다. (로그인 세션·설정·홈 배경 유지)
주요 기능
플로팅 펫 & 입력 집계
플로팅 펫 오버레이: 다른 앱 위에서도 캐릭터가 반응하며, 크기·불투명도·위치 저장 및 화면 회전(세로↔가로) 자동 보정을 지원합니다.
모양 선택: 캐릭터만 표시하는 폰형과 횟수판·설정 버튼을 함께 표시하는 홈형 중 선택할 수 있습니다.
플로팅 감정표현 & 상자 쿨타임: 플로팅 펫을 탭해 장착한 감정표현을 바로 사용하거나, 좌·우 보물상자 남은 시간을 함께 확인할 수 있습니다.
게임 모드 (터치 통과): 접근성 서비스 연결 시 Android 12+에서도 원하는 불투명도를 유지한 채 화면 터치를 방해하지 않고 통과시킵니다.
멀티플레이 기능: 방장 권한 양도, 멤버 내보내기, 공개 방 설정, 랜덤 방 입장을 지원합니다.
인벤토리 개선:
현재 캐릭터의 이모티콘 빠른 필터 토글 지원
탭별 정렬 개선 — 캐릭터(즐겨찾기 → 레어도 → 시리즈별), 액세서리(즐겨찾기 → 레어도), 이모티콘(즐겨찾기 → 레어도 → 캐릭터별), 최근 획득(획득 순 유지)
홈 화면 배경 커스터마이징: 기본 인벤토리 배경 외에도 원하는 사진을 선택해 맞춤 방식(채우기·원본 비율·중앙·늘리기), 바탕색(밝게/어둡게), 불투명도를 조절할 수 있습니다.
인앱 자동 업데이트: 꾸미기 → 설정 → 앱 업데이트에서 새 버전을 확인하고 SHA-256 무결성 검증 후 바로 설치할 수 있습니다.
권한 안내
| 권한 | 구분 | 용도 | |---|---|---| | 다른 앱 위에 표시 | 선택 | 플로팅 펫 오버레이 표시 | | 접근성 서비스 | 선택 | 다른 앱 사용 중 터치 횟수 집계 및 게임 모드 터치 통과 | | 알림 | 선택 | 플로팅 펫 포그라운드 서비스 유지 알림 | | 알 수 없는 앱 설치 | 선택 | 앱 내 업데이트 다운로드 후 바로 설치 실행 |

개인정보 보호: 접근성 서비스는 입력 횟수 집계와 게임 모드 터치 통과에만 사용되며, 입력 텍스트·화면 내용·좌표·계정 정보는 수집하거나 외부로 전송하지 않습니다.

참고 사항
백그라운드 유지: 화면을 닫은 뒤에도 자동 상자 열기와 입력 집계를 유지하려면 폰 설정에서 플로팅 펫 표시와 백그라운드 동기화를 켜 두세요.
데스크탑 전용 옵션 제외: Windows GPU 프레임 생성 호환성(항상 맨 위에 표시), 마우스 폴링 대응(포인터 위치 감지 비활성화) 등 PC 전용 옵션은 안드로이드에서 제외되었습니다.
항상 보물상자 표시 옵션: 홈 화면 펫 전용 옵션으로, 켜면 1,000회 미만에서도 두 상자 쿨타임이 표시되며 플로팅 펫에는 영향을 주지 않습니다.
